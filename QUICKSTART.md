# ⚡ Quick Start - Free Google Gemini Setup

Get the tool running in **5 minutes** with completely FREE Google Gemini API!

## 1️⃣ Get FREE API Key (2 minutes)

Click here: **https://aistudio.google.com/app/apikey**

- Click **"Create API key"**
- Copy the key
- Done! No credit card, no billing.

## 2️⃣ Set Environment Variable

```bash
export GOOGLE_API_KEY=paste_your_key_here
```

## 3️⃣ Run the Tool

```bash
cd ~/Projects/claude-zillow-automation
npm run dev
```

## 4️⃣ See Results!

The tool will:
- Load 3 sample properties
- Generate marketing descriptions
- Create Viewmax commands for videos/images/voiceovers
- Show everything ready to deploy

That's it! 🎉
